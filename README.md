# Registro al evento

## Descripción
Proyecto simple que valida la edad de una persona para dar acceso a un evento, usando formularios, JavaScript DOM y eventos.

## Instalación y ejecución
1. Clonar el repositorio:
```bash
git clone https://github.com/franco-lapalma/DesarrolloEnReact.git
```

2. Cambiar a la rama:
```bash
git checkout tarea1-js-esencial
```

3. Abrir el archivo `index.html` en un navegador para probar.
